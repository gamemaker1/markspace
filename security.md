# security policy

## supported versions

Fixes go into the `main` branch and the next release. Older releases do not
receive fixes.

## reporting a vulnerability

Report vulnerabilities privately through GitHub. The
[GitHub guide](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability#privately-reporting-a-security-vulnerability)
describes how to open a private report.
